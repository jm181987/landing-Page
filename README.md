# Landing Page

Ejercicio de construcción de una página de presentación con componentes React.

## Tecnologías

React y JavaScript.

## Inicio rápido

```bash
git clone https://github.com/jm181987/landing-Page.git
cd landing-Page
```

`npm install` y `npm run start`.

## Seguridad y mantenimiento

- Comprueba los scripts y variables de entorno antes de desplegar.
- No publiques credenciales ni datos sensibles.
- Registra los cambios y problemas con pasos de reproducción.
